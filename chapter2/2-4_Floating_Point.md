# 2.4. 부동소수점

### IEEE 754 부동소수점 연산 표준 기준

---

## 부동소수점의 한계

- 컴퓨터는 10진수를 2진수로 바꿔서 저장하기 때문에 이 과정에서 대부분 순환소수의 형태가 되거나 제한된 비트 범위를 벗어나는 경우가 많기 때문에 정확한 값을 저장하지 못하게 된다.
- `float_test.c` 참고

## 부동소수점 표시

- Single precision (float)
	- 부호 1비트, 지수 8비트, 가수 23비트
		- 아래 글은 Single precision 기준으로 풀어간다.
- Double precision (double)
	- 부호 1비트, 지수 11비트, 가수 52비트

- 정규화 값
	- Single precision 기준으로 가수 부분에 127의 Bias를 더한다.
	- 암시적 선두 1이 있다고 가정한다.

- 비정규화 값
	- 가수 필드가 전부 0일 경우 정규화 기준으로 -127이지만 이 경우는 특수하게
	  $E = 1 - Bias = -126$ 으로 다룬다.
	- 가수부가 전부 0이면 암시적 선두를 0으로 취급한다.
		 - 최초에 정규화 방식만 알고 있을 때는 부동소수점이 0.0도 제대로 표현하지 못한 다고 생각했지만 그렇지 않았다.
	- 0과 아주 근사한 매우 작은 값을 저장할 때 이처럼 가수 부분을 0으로 만들어 저장이 가능하다.
		- 지수 부분이 0이 아닌 값일 경우 $0.00..1 \times 2^{-126}$ 등의 수를 저장

- 특수 값
	- 지수 필드가 전부 1일 경우 특수한 값으로 다룬다.
	- 가수부가 전부 0일 경우 $\infty$ 혹은 $-\infty$ 를 해석한다. (오버플로의 표현으로도 사용이 가능)
	- 가수부가 0이 아닐 경우 `NaN` 으로 해석된다.

## 근사법

- 정확한 값을 저장하기 어려운 부동소수점의 특성상 가장 유사한 값이라도 저장하기 위해 rounding 연산을 한다.

- 현대 컴퓨터에는 일반적으로 FPU(부동소수점 연산 장치)가 기본으로 포함돼 있다.

- FPU에는 실제 가수부 비트보다 더 긴 공간(**G, R, S**)이 있어이 값을 기준으로 1xx (올림), 0xx (버림)을 진행한다. 이 비트가 정확히 100 (절반) 일 경우엔 비트를 올리는 기준을 짝수가 되도록 한다는 규칙이 있다.
	- 사사오입의 규칙에 따라 100도 무조건 올린다면 통계적으로 대량의 소수를 다룰때 결과값이 점점 커지는 양의 편향이 발생하기 때문.
	- 가수부의 LSB (0/1) 의 비율은 같기 때문에 짝수 규칙을 따르도록 설계됨
